# Artwork credits

Artwork by [Kenney](https://kenney.nl), used under Creative Commons CC0.
The eight source-pack notices are preserved verbatim in Licenses/.

- Puzzle Pack 1: five glossy gems, atlas slots 1-5.
- Platformer Assets Base: darkened iron bomb with selectively brightened source
  reflection spots, and flagRed, slots 6-7.
- Animal Pack Remastered: Round/snake, rotated into four directions (9-12).
  Its cropped forehead texture forms the rounded body segment (13).
- Board Game Icons: resource_apple, recolored red with a green leaf and brown
  stem, plus a small highlight (14). The leaf color is masked to the source's
  disconnected leaf silhouette, preserving the transparent outlined region.
- Rune Pack: eight Grey/Rectangle runes 001-008, tinted for distinct pairs
  (17-24).
- Fantasy UI Borders: panel-border-002, gold-tinted (25), rendered in eight
  slices around the window so its corners do not stretch.
- UI Pack - Adventure: button_grey, recolored into normal, hover, pressed and
  disabled states in Buttons.tga. Three slices preserve end caps at each size.

Original Flightpath Arcade artwork: covered tile (8) and card back (16).
Slot 15 is transparent; the header crest was removed. MIT license: LICENSE.txt.
Original and CC0 rights remain distinct.

Minimap.tga: original broad gold wings and dark circular backing, plus the
existing Kenney Puzzle Pack 1 cyan diamond. The refined selected concept A
omits the extra gold ring and uses an optically separated smaller gem.
The minimap uses the selected refined winged-gem design.
The native 20/24/32-pixel comparisons are texture previews, not live WoW captures.

Runtime formats: Arcade.tga is 512 x 256; Buttons.tga is 256 x 256; Minimap.tga
is 64 x 64 (16 KiB texture data). All are uncompressed 32-bit RGBA with
four-pixel transparent gutters; combined texture data is 784 KiB before driver
overhead. These three textures serve the original four games; Frost Run adds the textures described below.
All four games use Kenney artwork. Notices verified on 2026-10-10.

## Frost Run

Kenney [Tiny Ski](https://kenney.nl/assets/tiny-ski), CC0: skier/air poses, snow beast poses, trees, rock, stump, snowman, ramps, flags, snow terrain, decorative nets and signs. Static poses are animated by the addon; tall trees combine their matching top/base tiles. The terrain and shoulder atlases assemble selected tiles into a looping snowy course. The unchanged source notice is `Licenses/Tiny Ski.txt`. Only the selected derived TGA textures are included.
